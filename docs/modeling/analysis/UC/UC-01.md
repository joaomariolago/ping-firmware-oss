# UC-01: Get Device Information

## Objective

Define how the host retrieves **device type**, **hardware revision**, and **firmware version** through the standard communication interface for identification and diagnostics.

## Requirements

| **ID** | **Description** |
| -------- | -------- |
| [**FR-01**](../FR/FR-01.md) | The system shall support a standard byte-stream protocol for communication with the host. |
| [**FR-02**](../FR/FR-02.md) | The system shall only accept messages over the standard communication interface if the message checksum is valid. |
| [**FR-03**](../FR/FR-03.md) | The system shall allow the host to query device type, hardware revision, firmware version, and protocol version. |
| [**NFR-01**](../NFR/NFR-01.md) | The standard communication interface shall remain operational after receiving a corrupted or invalid message. |
| [**NFR-02**](../NFR/NFR-02.md) | All *GET* messages shall not alter the state of the system. |

## Actors

* **Host** – External controller or computer communicating with the device via the byte-stream protocol.

## Preconditions

* Device powered and communication interface operational.

## Entry Condition

* Host sends a valid **Get Device Information** request.

## Main Flow

1. Host sends **Get Device Information** request.
2. System validates the message.
3. System retrieves:

   * **Device Type** (`u8`)
   * **Device Revision** (`u8`)
   * **Firmware Version** (`u8`, `u8`, `u8` → Major.Minor.Patch)
   * **Protocol Version** (`u8`)
4. System assembles and sends a response message containing these parameters.
5. Host processes and stores the received information.

## Alternate Flow

* No alternate flow.

## Post-conditions

* Device remains operational and ready for further communication.

## Business Rules

1. All identification fields are **unsigned 8-bit integers**.
2. **Firmware version** format is `Major.Minor.Patch`.
