# UC-07: Get Single Distance Measurement

## Objective

Define how the host requests and receives a **single distance measurement** from the system through the standard communication interface.
This operation provides an instantaneous range measurement including distance and confidence values.

## Requirements

| **ID**                         | **Description**                                                                                                   |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------- |
| [**FR-01**](../FR/FR-01.md)    | The system shall support a standard byte-stream protocol for communication with the host.                         |
| [**FR-02**](../FR/FR-02.md)    | The system shall only accept messages over the standard communication interface if the message checksum is valid. |
| [**FR-14**](../FR/FR-14.md)    | The system shall allow the host to request a single distance measurement.                                        |
| [**FR-15**](../FR/FR-15.md)    | The system shall include both distance and confidence values in the measurement response.                         |
| [**NFR-01**](../NFR/NFR-01.md) | The standard communication interface shall remain operational after receiving a corrupted or invalid message.     |
| [**NFR-02**](../NFR/NFR-02.md) | All *GET* messages shall not alter the state of the system.                                                      |

## Actors

* **Host** – External controller or computer communicating with the device via the byte-stream protocol.

## Preconditions

* Device powered and communication interface operational.
* Sonar ready to perform a valid measurement.

## Entry Condition

* Host sends a valid **Get Single Distance Measurement** request.

## Main Flow

1. Host sends **Get Distance Measurement** request.
2. System validates the message and triggers a single sonar measurement.
3. System computes the resulting parameters:
   * **Distance** (`u32`, millimeters)
   * **Confidence** (`u8`, percentage `0–100`)
4. System sends a response message containing both values.
5. Host processes and stores the received data.

## Alternate Flow

* If message validation fails, the system discards it without performing a measurement.
* If measurement fails, the system returns zero confidence and a default distance of `0 mm`.

## Post-conditions

* Single measurement completed and transmitted.
* Device remains ready for subsequent operations.

## Business Rules

1. **Distance** shall be represented as an **unsigned 32-bit integer** (`u32`) in **millimeters (mm)**.
2. **Confidence** shall be represented as an **unsigned 8-bit integer** (`u8`) in the range **0–100**.
3. When **Continuous Measurement Streaming** is enabled, new distance messages are transmitted automatically as soon as available.
