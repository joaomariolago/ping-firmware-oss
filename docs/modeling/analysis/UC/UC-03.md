# UC-03: Configure Speed of Sound

## Objective

Define how the host reads or writes the **Speed of Sound** parameter used by the system for distance and range calculations.
This parameter defines the conversion between signal travel time and measured distance in the medium, expressed in millimeters per second.

## Requirements

| **ID**                         | **Description**                                                                                                   |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------- |
| [**FR-01**](../FR/FR-01.md)    | The system shall support a standard byte-stream protocol for communication with the host.                         |
| [**FR-02**](../FR/FR-02.md)    | The system shall only accept messages over the standard communication interface if the message checksum is valid. |
| [**FR-06**](../FR/FR-06.md)    | The system shall allow the host to query the current speed of sound value.                                       |
| [**FR-07**](../FR/FR-07.md)    | The system shall allow the host to set a new speed of sound value.                                               |
| [**NFR-01**](../NFR/NFR-01.md) | The standard communication interface shall remain operational after receiving a corrupted or invalid message.     |
| [**NFR-03**](../NFR/NFR-03.md) | The system shall apply and store updated configuration parameters only if they are valid.                         |
| [**NFR-04**](../NFR/NFR-04.md) | Important configuration parameters shall be stored in non-volatile memory.                                        |

## Actors

* **Host** – External controller or computer communicating with the device via the byte-stream protocol.

## Preconditions

* Device powered and communication interface operational.
* Current speed of sound value available in system configuration.

## Entry Condition

* Host sends a valid message to read or write the speed of sound.

## Main Flow

### Case 1: Read Speed of Sound

1. Host sends **Get Speed of Sound** request.
2. System validates the message and retrieves the current value (`u32`, millimeters per second).
3. System sends a response message containing the value.
4. Host processes and stores the received value.

### Case 2: Set Speed of Sound

1. Host sends **Set Speed of Sound** request containing a new `u32` value (mm/s).
2. System validates the message and checks the value range.
3. System updates and stores the new speed of sound.
4. System sends an acknowledgment message.
5. Host verifies the acknowledgment.

## Alternate Flow

* If message validation or value range check fails, the system discards the message and retains the previous value.

## Post-conditions

* Updated speed of sound value stored (persistent if supported).
* Device remains operational and responsive to subsequent commands.

## Business Rules

1. The **Speed of Sound** value shall be represented as an **unsigned 32-bit integer** (`u32`).
2. Units: **millimeters per second (mm/s)**.
3. The parameter shall directly affect all subsequent distance and range computations.
