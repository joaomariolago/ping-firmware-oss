# FR-15: Distance Measurement Response Structure

## Requirement Statement
The system shall include both **Distance** and **Confidence** values in the measurement response.

## Description
The system shall provide a structured response containing both **Distance** and **Confidence** parameters when a distance measurement is requested.
* **Distance** shall be represented as an unsigned 32-bit integer (`u32`) in millimeters (`mm`).
* **Confidence** shall be represented as an unsigned 8-bit integer (`u8`) ranging from 0 to 100, indicating the reliability of the measurement.
Both values shall be transmitted together in a single message following the standard byte-stream protocol format.

## Rationale
Including both distance and confidence values enables:
* Host systems to assess measurement reliability and data quality
* Consistent interpretation of range results across different operational modes
* Diagnostic evaluation and validation of sonar performance
