# FR-12: Automatic Configuration Mode State Query

## Requirement Statement
The system shall allow the host to query the current **Automatic Configuration Mode** state.

## Description
The system shall provide a mechanism for the host to retrieve the **Automatic Configuration Mode** state through the standard communication interface.
This state, represented as an unsigned 8-bit integer (`u8`), indicates whether automatic configuration is enabled (`1`) or disabled (`0`).

## Rationale
Automatic configuration mode state querying enables:
* Verification of whether autonomous parameter adjustment is active
* Monitoring of operational mode for diagnostic and control purposes
* Synchronization between host control logic and device adaptive behavior
