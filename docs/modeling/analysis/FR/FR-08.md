# FR-08: Scan Parameters Query

## Requirement Statement
The system shall allow the host to query the current **Scan Start** and **Scan Length** parameters.

## Description
The system shall provide a mechanism for the host to retrieve the **Scan Start** and **Scan Length** parameters through the standard communication interface.
Both parameters, expressed in millimeters (`u32`), define the beginning and the extent of the active scanning window used for acoustic measurements.

## Rationale
Scan parameter querying enables:
* Verification of the current measurement range configuration
* Consistency of scanning behavior across multiple devices
* Diagnostic validation of operational range limits and measurement window alignment
