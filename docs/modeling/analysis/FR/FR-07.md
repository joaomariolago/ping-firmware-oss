# FR-07: Speed of Sound Configuration

## Requirement Statement
The system shall allow the host to set a new **Speed of Sound** value.

## Description
The system shall provide a mechanism for the host to assign a new **Speed of Sound** parameter through the standard communication interface.
The value, expressed in millimeters per second (`u32`), shall replace the current configuration only if it is valid.

## Rationale
Speed of sound configuration enables:
* Adjustment of distance computation to match environmental conditions (temperature, salinity, or medium type)
* Calibration and optimization of measurement accuracy
* Consistency between multiple devices operating under varying acoustic conditions
