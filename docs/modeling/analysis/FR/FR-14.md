# FR-14: Single Distance Measurement Request

## Requirement Statement
The system shall allow the host to request a single **Distance Measurement**.

## Description
The system shall provide a mechanism for the host to initiate a single distance measurement through the standard communication interface.
Upon receiving a valid request, the system shall perform one acoustic measurement cycle and return a structured response containing the computed **Distance** (`u32`, millimeters) and **Confidence** (`u8`, percentage 0–100).

## Rationale
Single distance measurement requests enable:
* On-demand range acquisition without enabling continuous streaming
* Verification and calibration of sonar operation during setup or diagnostics
* Controlled measurement triggering for host-managed data collection processes
