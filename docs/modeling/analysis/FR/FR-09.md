# FR-09: Scan Parameters Configuration

## Requirement Statement
The system shall allow the host to set new **Scan Start** and **Scan Length** parameters.

## Description
The system shall provide a mechanism for the host to assign new **Scan Start** and **Scan Length** values through the standard communication interface.
Both parameters, expressed in millimeters (`u32`), define the beginning and the extent of the scanning window and shall be applied only if the values are valid and within operational limits.

## Rationale
Scan parameter configuration enables:
* Adjustment of the active measurement window to match the target range
* Optimization of scanning performance for different operational environments
* Customization of range limits for application-specific requirements
