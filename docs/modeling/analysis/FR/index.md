# List of Functional Requirements (FRs)

| **ID** | **Description** |
| -------- | -------- |
| [**FR-01**](./FR-01.md) | The system shall support a standard byte-stream protocol for communication with the host. |
| [**FR-02**](./FR-02.md) | The system shall only accept messages over the standard communication interface if the message checksum is valid. |
| [**FR-03**](./FR-03.md) | The system shall allow the host to query device type, hardware revision, firmware version, and protocol version. |
| [**FR-04**](./FR-04.md) | The system shall allow the host to query the current Device ID. |
| [**FR-05**](./FR-05.md) | The system shall allow the host to set a new Device ID. |
| [**FR-06**](./FR-06.md) | The system shall allow the host to query the current speed of sound value. |
| [**FR-07**](./FR-07.md) | The system shall allow the host to set a new speed of sound value. |
| [**FR-08**](./FR-08.md) | The system shall allow the host to query the current scan start and scan length parameters. |
| [**FR-09**](./FR-09.md) | The system shall allow the host to set new scan start and scan length parameters. |
| [**FR-10**](./FR-10.md) | The system shall allow the host to query the current measurement streaming state. |
| [**FR-11**](./FR-11.md) | The system shall allow the host to enable or disable continuous measurement streaming. |
| [**FR-12**](./FR-12.md) | The system shall allow the host to query the current automatic configuration mode state. |
| [**FR-13**](./FR-13.md) | The system shall allow the host to enable or disable automatic configuration mode. |
| [**FR-14**](./FR-14.md) | The system shall allow the host to request a single distance measurement. |
| [**FR-15**](./FR-15.md) | The system shall include both distance and confidence values in the measurement response. |
