# FR-06: Speed of Sound Query

## Requirement Statement
The system shall allow the host to query the current **Speed of Sound** value.

## Description
The system shall provide a mechanism for the host to retrieve the **Speed of Sound** parameter through the standard communication interface.
This value, expressed in millimeters per second (`u32`), defines the acoustic propagation speed in the medium used in distance and range calculations.

## Rationale
Speed of sound querying enables:
* Propagation speed in medium changes due to environmental factors (temperature, salinity, pressure, etc.)
* Users can adjust the speed of sound to match the medium they are operating in (e.g. water, air, etc.)
* Verification of the current acoustic parameters configuration
* Consistent distance measurement and calibration across devices
* Diagnostic evaluation of range computation parameters
