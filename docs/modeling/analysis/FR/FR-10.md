# FR-10: Measurement Streaming State Query

## Requirement Statement
The system shall allow the host to query the current **Measurement Streaming State**.

## Description
The system shall provide a mechanism for the host to retrieve the current **Measurement Streaming State** through the standard communication interface.
This state, represented as an unsigned 8-bit integer (`u8`), indicates whether continuous measurement streaming is enabled (`1`) or disabled (`0`).

## Rationale
Measurement streaming state querying enables:
* Verification of whether continuous measurement streaming is active
* Synchronization between host-side data handling and device measurement behavior
* Diagnostic confirmation of streaming configuration consistency across sessions
