# FR-04: Device ID Query

## Requirement Statement
The system shall allow the host to query the current **Device ID**.

## Description
The system shall provide a mechanism for the host to retrieve the **Device ID** through the standard communication interface.
The Device ID uniquely identifies the device within a network or multi-device configuration.

## Rationale
Device ID querying enables:
* Unique device addressing and management in multi-device networks
* Verification of correct device configuration
* System diagnostics and identification consistency
